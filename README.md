# Projeto Prático - Design Profissional & GitHub Foundations

Repositório desenvolvido por **Gabriel Hiroshi Koseko** para a aplicação prática dos conceitos da trilha **GitHub Foundations** (Microsoft Learn), no curso de Engenharia de Software da **Universidade Positivo**.

## Conceitos Aplicados
* **Controle de Versão:** Rastreamento de histórico com Git.
* **Fluxo de Branches:** Criação de branch paralela para desenvolvimento isolado de documentação.
* **Pull Request & Code Review:** Integração formal de alterações via Pull Request com Merge na main.
* **Sintaxe Markdown:** Estruturação visual e padronizada da documentação técnica.

## Certificação
* Trilha GitHub Foundations concluída no Microsoft Learn.
